正式上線前記得在 admin.html 把 ALLOW_TEST_MODE 改 false
首次部署設定（管理員看）：
1. Google Cloud Console → 建立 OAuth 2.0 Client ID（類型：Web 應用程式）
2. 已授權 JavaScript 來源加：
   https://zway-education.github.io
3. 拿到 Client ID 後，編輯本檔（admin.html）：
   搜尋 YOUR_GOOGLE_CLIENT_ID → 替換成你的 Client ID
4. 編輯白名單 ADMIN_EMAILS（也在本檔內）— 列出所有可進後台的 Google 帳號 email
5. 推到 GitHub Pages（lessson-test-Management）→ 後台網址：
   https://zway-education.github.io/lessson-test-Management/
